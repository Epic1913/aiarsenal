快速开始

开源 · 自行部署 · 数据完全在自己手里（本站不提供在线体验服务）

1获取源码

从 GitHub 克隆仓库，按 README 准备运行环境（Node / Go / PostgreSQL + pgvector / Redis）。

git clone https://github.com/aiarsenal/aiarsenal.git
cd aiarsenal

2本地一键起全栈（macOS / Windows）

脚本自动初始化 10 个数据库（基线 SQL 已固化，无需迁移）、构建前后端并拉起三个服务。

bash scripts/local-test.sh deploy      # macOS
bash scripts/local-test-win.sh deploy  # Windows（Git Bash）

默认账号 hi / aiarsenal123（详见 README「默认账号」节，登录后请立即修改）。

3服务器部署（Ubuntu）

systemd + nginx 一键部署；桌面客户端（macOS .dmg / Windows .msi）从 GitHub Releases 下载，连接你自己的服务端。

sudo bash deploy.sh rebuild-db   # 首次建库（⚠️ 会清空重建）
sudo bash deploy.sh test         # 测试环境：纯 HTTP + /etc/hosts

完整步骤与桌面客户端说明见 README · 下载 Releases
